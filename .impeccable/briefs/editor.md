# Editor UML — Operate

## Direction contract
THESIS: Una mesa de diagramado con el lienzo como protagonista. La forma familiar de una aplicación de escritorio sigue el encargo explícito del usuario.

OWN-WORLD: Grafito azulado para la navegación, superficies minerales claras y petróleo para acciones y selección. Source Sans 3 para la interfaz; IBM Plex Mono exclusivamente para código y miembros UML. Separación tonal, esquinas de 6–8 px y sombras reservadas a superficies flotantes.

STORY: Encontrar el documento, insertar clases, conectarlas y editar la selección en el panel derecho. Abrir Mermaid cuando hace falta y ver siempre el estado de guardado.

FIRST VIEWPORT: Cabecera compacta; navegación de 52 px, explorador de 228 px, lienzo flexible y propiedades de 264 px. La acción Nuevo diagrama vive en el explorador. El lienzo ocupa toda la altura disponible; el código es secundario y se puede mostrar en paralelo.

FORM: Dirección 3 de siete referencias consideradas: documentación de ingeniería suiza, cartografía de redes, catálogo técnico de precisión, cuaderno académico, atlas de sistemas, biblioteca de normas y fichas de arquitectura. Semilla 7b286eaa. El encargo de escritorio y la preferencia visual confirmada prevalecen sobre cualquier alternativa. La referencia grafito aporta disciplina de separación y aislamiento de acciones destructivas; el catálogo aporta legibilidad densa; el folio aporta consistencia entre versiones, sin importar motivos decorativos.

SIGNATURE: La selección de una clase recorre el mismo acento petróleo entre el nodo y sus propiedades; al soltarla, un breve cambio de trazo confirma la nueva posición sin mover el texto.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
